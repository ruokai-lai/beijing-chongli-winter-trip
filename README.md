- **1/15 周五**:抵达北京,住东城区。
- **1/16 周六**:倒时差,天坛,烤鸭。
- **1/17 周日**:高铁去崇礼(北京北 → 太子城,约 1 小时 20 分)。
- **1/18 到 1/19**:滑雪,孩子上半天私教课。
- **1/20 周三**:上午滑雪,下午回北京,避开春运。
- **1/21 周四**:休整,什刹海与胡同。
- **1/22 周五**:国家博物馆、王府井。
- **1/23 周六**:故宫 + 景山。
- **1/24 周日**:慕田峪长城(缆车、滑道)。
- **1/25 周一**:颐和园(故宫、国博周一闭馆)。
- **1/26 周二**:环球影城(工作日)。
- **1/27 周三**:中国科技馆。
- **1/28 周四**:机动日。
- **1/29 周五**:798 与胡同。
- **1/30 周六**:收拾行李,住机场附近。
- **1/31 周日**:回程。

## 崇礼雪场

| 雪场 | 特点 | 适合吗 |
|---|---|---|
| 太舞 | 初中高级道约 3:4:3,有青少年专区 | 首选 |
| 富龙 | 有初学者「首滑专属服务」 | 可考虑 |
| 万龙 | 雪道大,新手信息少 | 备选 |
| 云顶 | 13 条高级道,仅 2 条初级道 | 不适合 |

票价为旧数据(太舞 2024-25 雪季平日约 120 元,周末约 180 元),2026-27 雪季价格以雪场公布为准。
